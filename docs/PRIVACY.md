# Privacy

**PocketNotebook is local-first.** There is no account, no server, no
telemetry, and no analytics SDK.

## What stays on the device

- Notebooks, sources, chunks, chat history, artifacts — SQLite in app storage
- Downloaded model weights — app-private files, excluded from backups
- Everything the AI generates — generated by models running in-process
  (llama.cpp via JNI). No network involved.

## What touches the network (only when you ask)

| Action | Endpoint |
|---|---|
| Model download / search | `huggingface.co` (public API + file CDN) |
| "Add web page" source | the URL you enter |

## V0.1 alpha caveats (be aware)

- **Voice typing** uses the device `SpeechRecognizer` — on most phones that
  means Google's speech service, which may process audio in the cloud. Don't
  use it for sensitive input.
- **Audio overview narration** uses the device TTS engine. Offline if the
  engine is offline (most are), but that depends on your device/ROM.

Both paths exist only until the LFM3-Audio-2B native integration lands
(post Phase 0 spike, issue #1), which moves speech in/out fully on-device.

## Permissions

- `INTERNET` — model downloads, URL sources
- `RECORD_AUDIO` — voice typing only (opt-in at the mic button)
- `POST_NOTIFICATIONS` — download/bake progress
- `FOREGROUND_SERVICE(+DATA_SYNC)` — ingestion, downloads, audio baking
